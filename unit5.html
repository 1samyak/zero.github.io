Web Technology • Unit 5

Web Security & Advanced Topics

Learn essential security concepts, deployment and modern web practices.

5.1 Web Security

  • XSS: injection of malicious client-side scripts.
  • SQL Injection: manipulating database queries through unsafe input.
  • CSRF: tricking an authenticated browser into making an unwanted request.
  • HTTPS: encrypts HTTP communication using TLS.

5.2 Security Practices

  • Validate and sanitize input.
  • Use parameterized database queries.
  • Apply authentication and authorization correctly.
  • Store passwords using strong password hashing.
  • Keep dependencies and server software updated.

5.3 Deployment

A typical deployment involves source control, build steps, hosting, DNS configuration, HTTPS and monitoring.

5.4 Web Performance

Optimize images, reduce unnecessary JavaScript/CSS, cache static resources, lazy-load where useful and measure real user performance.
