Web Technology • Unit 3

JavaScript

Make web pages interactive with client-side programming.

3.1 JavaScript Fundamentals

JavaScript is a programming language commonly used in browsers to add behavior and interactivity.

  • Variables: let and const
  • Data types: string, number, boolean, object, undefined, null, etc.
  • Control flow: if/else, switch, loops
  • Functions, arrays and objects

3.2 DOM

The Document Object Model represents the page as a tree of objects. JavaScript can select elements, change content/styles and respond to events.

const button = document.querySelector("#btn"); button.addEventListener("click", () => { document.querySelector("#msg").textContent = "Clicked!"; });

3.3 Modern JavaScript

Important concepts include arrow functions, template literals, destructuring, modules, promises and async/await.
