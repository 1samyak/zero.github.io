Web Technology • Unit 4

Server-Side & Database

Understand backend processing, APIs, sessions and data storage.

4.1 Server-Side Programming

Server-side code runs on a server and can handle authentication, business logic, validation and database operations.

4.2 HTTP Request–Response

  • GET — retrieve data
  • POST — submit/create data
  • PUT/PATCH — update data
  • DELETE — remove data

4.3 APIs

A web API provides programmatic access to resources. REST APIs commonly use HTTP methods and JSON representations.

4.4 Databases

Relational databases store structured data in tables with relationships. NoSQL databases use models such as documents, key-value pairs or graphs.

4.5 Sessions & Cookies

Cookies are small pieces of data stored by the browser. Sessions allow a server to maintain user state across requests.
