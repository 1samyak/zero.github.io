Web Technology • Unit 1

Introduction to Web Technology

Foundations of the Web, internet, browsers, protocols and basic HTML.

1.1 Internet and World Wide Web

The Internet is a global network of interconnected computer networks. The World Wide Web is a service that runs on the Internet and uses web pages, hyperlinks and web protocols.

1.2 Web Architecture

  • Client: browser or application requesting resources.
  • Server: system that processes requests and returns resources.
  • HTTP/HTTPS: protocols used for web communication.
  • URL: address used to locate a web resource.

1.3 HTML Basics

HTML (HyperText Markup Language) provides the structure of a web page using elements and attributes.

<!DOCTYPE html> <html> <head><title>My Page</title></head> <body><h1>Hello Web</h1></body> </html>
