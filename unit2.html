Web Technology • Unit 2

HTML & CSS

Build structured pages and style them with modern CSS.

2.1 HTML Elements

Common elements include headings, paragraphs, links, images, lists, tables, forms, semantic containers and multimedia elements.

2.2 Forms

Forms collect user input using controls such as text fields, password fields, radio buttons, checkboxes, select menus and submit buttons.

2.3 CSS

CSS controls presentation. It can be applied inline, internally, or through an external stylesheet. The cascade, specificity and inheritance determine which declarations apply.

body { font-family: sans-serif; } .card { padding: 20px; border-radius: 12px; } .card:hover { transform: translateY(-2px); }

2.4 Responsive Design

  • Use flexible layouts such as Flexbox and Grid.
  • Use relative units where appropriate.
  • Use media queries for different screen sizes.
